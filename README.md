# GameZone

GameZone es una página web de ejemplo para una tienda de videojuegos desarrollada como proyecto de práctica de HTML y CSS para Talento Tech.

## Características
* Catálogo de videojuegos y monedas virtuales.
* Diseño responsive con adaptabilidad móvil.
* Sección de reseñas de usuarios.
* Formulario de contacto integrado.

## Tecnologías utilizadas
* HTML5
* CSS3
* Flexbox
* CSS 
* Media Queries
* Google Fonts

## Formulario de contacto
El formulario de contacto utiliza Formspree para procesar el envío de mensajes sin necesidad de un servidor propio.

Se conecta mediante el atributo `action` de la etiqueta `<form>` utilizando el método POST.

Los datos enviados son:
* Nombre
* Correo electrónico
* Mensaje
